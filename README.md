# AI Skin Disease Classifier & Detector

This Hugging Face Space hosts an interactive computer vision application that classifies dermatological skin lesion images into 7 diagnostic categories using a fine-tuned ResNet-18 model trained on the HAM10000 dataset.

## Features
- **7 Classifications:** Actinic Keratosis, Basal Cell Carcinoma, Benign Keratosis, Dermatofibroma, Melanoma, Melanocytic Nevi, Vascular Lesions.
- **Real-Time Inference:** Fast CPU inference using PyTorch.
- **Educational Demo:** Built with Flask and Gradio.

## Medical Disclaimer
This application is strictly for **educational and portfolio demonstration purposes**. It is not intended to provide medical diagnoses, treatment, or clinical advice.
